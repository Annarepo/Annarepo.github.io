Three-tier microservices platform on Amazon EKS

A three-tier application running on EKS with the entire environment — VPC, subnets and managed node groups — provisioned by Terraform rather than clicked together in the console. Node groups are spread across multiple availability zones so no single AZ failure takes the application down.

Delivery runs the same way it does in the pipeline above: GitHub Actions builds, tests and publishes images, then ArgoCD reconciles the cluster declaratively from Git. Cluster monitoring gives real-time visibility into application and infrastructure health.

End-to-end Kubernetes CI/CD pipeline

A complete containerised deployment pipeline written from the ground up — Docker images pushed to a private registry, raw Kubernetes manifests for Deployment, Service and Ingress, and a Helm chart for templated releases.

The interesting part is the handoff between CI and CD. Instead of letting the pipeline run kubectl apply, GitHub Actions updates the image tag in the Helm chart and commits it back, and ArgoCD takes it from there. Git stays the single source of truth, and a rollback is just a revert.
